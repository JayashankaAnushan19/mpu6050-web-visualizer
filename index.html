Arduino Uno · MPU6050 · Web Serial

MPU6050 Projects

Small hardware projects with an MPU6050 motion sensor. Each one streams over USB to a web page, so you can watch it live in Chrome or Edge. No app to install. Each project also has a demo mode, so you can try it without hardware.

01

Motion Visualizer

A 3D board that follows the sensor's roll, pitch and yaw, with an artificial horizon, live charts and CSV recording.

  • Three.js
  • uPlot
  • complementary filter
Open Demo Source
02

Digital Leveler

A spirit level with five LEDs. The light glides like a bubble, and only the green centre LED is lit when level. The page mirrors the LEDs and adds a vial and a bullseye.

  • 5 PWM LEDs
  • EEPROM settings
  • Canvas
Open Demo Source

Each project has its own Arduino sketch. Upload the one you want to use, then open its page and click Connect. Running locally? Double-click start.bat.
